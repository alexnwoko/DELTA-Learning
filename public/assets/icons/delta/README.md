# DELTA icons in OCHA style

Eight icons for dashboard titles that the OCHA Humanitarian Icons set does not cover. The Frontend lane drew them on 2026-10-18 at Alex's request. They follow OCHA's style: solid filled shapes on a 100 by 100 grid, with cut-outs for detail.

| File | Title |
|---|---|
| extraterrestrial.svg | Extraterrestrial hazard (meteor) |
| chemical.svg | Chemical hazard (flask) |
| multi-hazard.svg | All hazards |
| evacuated.svg | Evacuated people (person leaving through an exit) |
| relocated.svg | Relocated people (house to house) |
| compare.svg | Compare events |
| duration.svg | Duration (stopwatch) |
| magnitude.svg | Magnitude (gauge) |

They are DELTA's own work, not OCHA's, so they carry no OCHA credit. The master copies are in `DELTA_Version_2/80_Frontend_and_Design_System/icons/delta-drawn-ocha-style/`.
